# cfgdrift

CLI-утилита, которая сравнивает два конфигурационных файла и показывает, чем они
отличаются — «дрейф» конфигурации.

## Поддерживаемые форматы

| Формат | Поддержка       |
|--------|---------------- |
| JSON   | да              |
| YAML   | пока нет        |
| TOML   | пока нет        |

## Использование

```bash
cfgdrift <база> <сравниваемый>
```

### Аргументы

| Аргумент         | Обязательный | Описание                                                         |
|------------------|--------------|---------------------------------------------------------------- |
| `<база>`         | да           | путь к файлу конфигурации, который берётся за исходный           |
| `<сравниваемый>` | да           | путь к файлу конфигурации, который сравнивается с базой          |

Оба аргумента — это пути к файлам (относительные или абсолютные).

| Символ | Значение                                                       |
|--------|------------------------------------------------------------- |
| `-`    | ключ есть только в `<база>`                                    |
| `+`    | ключ есть только в `<сравниваемый>`                            |
| `~`    | ключ есть в обоих, но значение изменилось: `база → сравниваемый` |

### Пример

`base.json`:

```json
{
  "server": { "host": "localhost", "port": 8080 },
  "logging": { "level": "info" },
  "features": ["auth", "cache"]
}
```

`current.json`:

```json
{
  "server": { "host": "localhost", "port": 9090 },
  "features": ["auth", "cache"],
  "tracing": { "enabled": true }
}
```

Запуск:

```bash
cfgdrift base.json current.json
```

Вывод:

```
Найдены различия:
  ~  значение изменилось (было → стало)
  -  ключ есть только в первом файле
  +  ключ есть только во втором файле

- logging.level: "info"
~ server.port: 8080 → 9090
+ tracing.enabled: true

итого: 3 (изменено 1, только в первом 1, только во втором 1)
```

## Коды возврата

| Код | Значение                          |
|-----|---------------------------------- |
| `0` | конфигурации идентичны             |
| `1` | найдены различия                  |
| `2` | ошибка загрузки или разбора файла  |
